# Colour

Two product themes share **paper, linen and charcoal**. They split only on
`primary`: Sage for the player app, gold for the referee tool. Harvested from
the approved Claude Design canvases, not invented here.

Storybook also keeps **Player — Original/Nelson** — the pre-canvas neon Player —
so the two Player looks can sit on the same page. It is a comparison skin, not
a product theme. To match it, use the toolbar: Theme →
**Player — Original/Nelson**, Mode → **Dark**.

Light is what those canvases are. Dark is derived. **`primary` holds the same
value in both modes.**

<Rule>

  Every colour below is painted from the live custom property, and every hex is
  read from `tokens/dist/tokens.ts`. Nothing on this page is typed by hand, so
  it cannot drift from the token contract.

</Rule>

## Contrast

Each foreground token measured against the background it is paired with, in both
modes. Ratios are WCAG 2.1; the grade is for normal-size body text, so **AA
large** means the pair is only safe at display sizes or on non-text elements.

The `X` / `X-foreground` pairs are discovered from the token names, so a new pair
in the contract appears here on its own.

{PRODUCT_THEMES.map((product) => (
  <section key={`contrast-${product}`}>
    <h3>{THEME_LABEL[product]}</h3>
    <TwoUp
      product={product}
      render={(mode) => <ContrastTable mode={mode} product={product} />}
    />
  </section>
))}
