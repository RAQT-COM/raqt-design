# Colour

Raqt is **green-grounded**, not grey with a green accent. The neutral ramp is
tinted green all the way down, so a dark screen reads as turf rather than as
charcoal.

Dark is the default mode. Light is derived from it. **`primary` holds the same
value in both** — the brand green is the one colour that never moves.

<Rule>

  Every colour below is painted from the live custom property, and every hex is
  read from `tokens/dist/tokens.ts`. Nothing on this page is typed by hand, so
  it cannot drift from the token contract.

</Rule>

## The semantic layer

The only layer components touch. Names match shadcn's, so `shadcn add` output
works against Raqt with no rewiring; the Raqt-only additions sit alongside and
never rename shadcn's.

## Contrast

Each foreground token measured against the background it is paired with, in both
modes. Ratios are WCAG 2.1; the grade is for normal-size body text, so **AA
large** means the pair is only safe at display sizes or on non-text elements.

The `X` / `X-foreground` pairs are discovered from the token names, so a new pair
in the contract appears here on its own.
